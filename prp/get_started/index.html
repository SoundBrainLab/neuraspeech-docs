Getting started

Once the environment has been installed, ensure that you have the following files required for PRP analysis:

  1. Preprocessed EEG files
    This toolbox assumes that EEG preprocessing has already been completed, including steps such as filtering, ICA, resampling, and epoching. The preprocessed data should be saved as mne.Epochs in .fif files in the same folder. It is recommended that each EEG epoch correspond to a single stimulus audio file. If an epoch contains responses to multiple consecutive audio files, specify this in the metadata file (see below).

  2. TextGrid files TextGrid files containing the phoneme annotations of the audio tracks corresponding to the epochs. Each TextGrild should have the same filename as the corresponding audio except the extension (e.g., 'track1.TextGrid' for 'track1.wav'). Place all TextGrids in the same folder.

  3. Metadata file
    Prepare a .csv spreadsheet that lists each EEG data file and its associated metadata. This spreadsheet will be used to link EEG data to the corresponding stimulus files. At minimum, the metadata file should include:

    • A column containing the EEG data filenames.
    • A column containing the stimulus filenames, including file extensions, for all epochs in the corresponding EEG file. Multiple stimulus filenames should be separated by semicolons (;).

    For example, a minimal metadata file may look like this:

    filename stim
    sub-01_task-alice.fif track1.wav;track2.wav;track3.wav;track4.wav;track5.wav

    In this example, sub-01_task-alice.fif contains five epochs, and the stim column lists the corresponding stimulus files in epoch order, separated by semicolons.

    If each epoch corresponds to multiple audio files, specify their filenames and presentation order using '+'. For example, the first epoch contains responses to tracks 1-3 and the second epoch contains responses to tracks 4-6:s

    filename stim
    sub-01_task-alice.fif track1.wav+track2.wav+track3.wav;track4.wav+track5.wav+track6.wav

    You are encouraged to add any additional metadata columns that may be useful for your analysis, such as participant ID, session, listening condition, etc. See misc/example_metadata.csv for an example.

  4. Stimulus files (optional)
    These are only needed if each of your EEG epochs contains responses to multiple stimuli. Place all speech or audio stimuli used in your EEG listening experiment in a single folder. Each stimulus should be saved as an individual .wav file.
